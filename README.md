# homebrew-aspire-cli

Unofficial Homebrew tap to install [Aspire CLI](https://github.com/microsoft/aspire) on macOS and Linux.

## Install

```sh
brew tap carminemars/aspire-cli
brew install aspire-cli
```

Then run:

```sh
aspire --help
```

## Update

```sh
brew update
brew upgrade aspire-cli
```

## Uninstall

```sh
brew uninstall aspire-cli
brew untap carminemars/aspire-cli
```
